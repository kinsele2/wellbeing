# Typical Week
#
# The recurring shape of a week. Google Calendar keeps the events; this keeps
# the structure underneath them.
#
# Format:   [mark] Day(s)  HH:MM-HH:MM  category  Label [?]
#
#   Day(s)  Mon | Mon-Fri | Sat,Sun
#   mark    (none) in both weeks
#           -      current week only (what goes away)
#           +      target week only (what gets added)
#   ?       at the end of a label = guess / provisional, drawn dashed
#
# Day labels:  @day Tue,Thu  office    (shown in the day header, column tinted)
#
# Comments start with "# ". Save and the Firefox tab updates.
